# 0011 The name of the site is Westwald Archive

Date: 2026-11-02
Decided by: owner
Status: accepted

## Context

The header of the prototype showed the game title, _Nelke & the Legendary Alchemists_, as the site name. That looks like an official site of the game. The owner wants a name that marks the site as a fan site. The name must be a term from the game or associated with the game, but not "Atelier" or "alchemy". Westwald is the town that the player builds in the game. A web search on 2026-11-02 found no site or product with the name "Westwald Archive".

## Decision

The site name is "Westwald Archive". The tagline is "Unofficial fansite for _Nelke & the Legendary Alchemists_". The header of each page shows both.

Rejected options:

- "Nelke Data", the name of the repository. It is close to the game title.
- An original name with no game words, for example "Kettle & Coin". The owner wants a term from the game.
- "Westwald Ledger", "The Governor's Ledger", "Granzweit Notes" and other names from the game. The owner chose "Westwald Archive".

## Consequences

The row "Site name" of `docs/requirements/site.md` and the row "Header" of `docs/design/site.md` hold the rule. The URL stays `https://arkased.github.io/NelkeData/`.
