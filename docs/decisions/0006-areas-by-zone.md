# 0006 The areas page groups the areas by zone

Date: 2026-11-02
Decided by: owner
Status: accepted

## Context

Decision 0005 made each category page a grid of game icons. The game groups its areas under top-level zones.

## Decision

The areas page shows 1 game panel for each top-level zone, in the order of the game. Each panel holds the names of the areas of the zone. The page is not an icon grid.

Rejected option:

- An icon grid of all areas, as on the other category pages. The owner said: "areas should be grouped based on top level zones first, should not be a grid layout".

## Consequences

The rule is in `docs/requirements/site.md`, row "Areas". The design is in `docs/design/site.md`, section "Areas page". The other category pages stay icon grids.
