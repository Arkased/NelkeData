# Requirements

What the owner requires of each feature, and for whom. 1 file per feature.

Each file holds a table of the owner's requirements. Each row has a name, the requirement, and its source: the owner's words with the date, or the owner's answer to a question. A row without an owner source does not belong here. The rules that the orchestrator makes, and the proof of each requirement, are in `docs/design/`.

A change of a requirement needs the approval of the owner before its design and its code.

Write what the system must do now. A removed feature leaves no text here.
